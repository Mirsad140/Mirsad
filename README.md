# مِرصاد — تطبيق أندرويد

مشروع تطبيق **مِرصاد** من إنتاج **المكتبة العدنانية**.

## ما الذي يحدث بعد رفع الملفات؟
1. افتح تبويب **Actions** في GitHub.
2. ستظهر عملية باسم **Build Mirsad APK**.
3. انتظر حتى تظهر علامة صح خضراء.
4. افتح العملية ثم انزل إلى **Artifacts**.
5. اضغط **Mirsad-APK** لتحميل ملف ZIP.
6. فك الضغط وستجد `Mirsad.apk`.
7. أرسله إلى هاتف أندرويد وثبته.

## تحديث الأخبار
التطبيق يحاول قراءة آخر نسخة من:
`news.json`

من مستودع GitHub، وإذا تعذر الإنترنت يستخدم النسخة المحفوظة داخل التطبيق.

لتحديث الأخبار لاحقًا يكفي تعديل ملف `news.json` في المستودع ثم إعادة فتح التطبيق والضغط على زر التحديث.
